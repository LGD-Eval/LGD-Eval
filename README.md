# LGD-Eval · 独立评测（Independent Evaluation）

> 中立第三方评测机构 —— 验证自治之物的治理主张
> 隶属：凡自治之物（总名）· LGD 治理学（内核 Lifecycle Governance Doctrine）· 创造术家族（引擎）
> 官方英文：Evidence-Gated AI Lifecycle Governance

## 我们做什么
- **评测协议**（evaluation-protocol）：公开评测标准 —— 测试专家手册中立化首发
- **评测报告**（evaluation-reports）：独立第三方实测报告（含 MedXpert 首份中立评测）
- **评测存证**（evaluation-evidence）：哈希 + 时间戳 + 区块链锚定（证据公开、不可抵赖）
- **技能审计**（skill-audit）：manifest / prompt 投毒检测工具（评测 MVP）

## 中立声明
- 本号不持有被评测方代码（利益隔离）
- 每份报告含完整可复放步骤（他人可复核）
- 评测方与被评测方无利益关系（不自查原则：产出者不查自己）
