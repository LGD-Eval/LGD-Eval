# LGD 评测引擎 · 独立第三方技能评测

独立第三方技能评测工具集：五维评测 + 安全扫描 + 18 维完整性审计。

## 三引擎

- `evaluate.py`：五维评测 → Trust Score + 等级
- `skillgate.py scan`：安全扫描（支持 `# skillgate: ignore` 行级抑制注释）
- `lgd_audit.py`：18 维审计（结构/清洁度/AI 友好/LGD 三律/评测完整性/维护性/失控/国际合规）

## 已知边界（诚实披露）

- 审计判**结构性**问题，不判内容是否属实
- 安全扫描对含检测规则字符串的代码（扫描器自身）存在固有误报，已用
  `# skillgate: ignore` 注释机制抑制并说明
- 建议对关键结论做人工复核

详见 `SKILL.md`。
