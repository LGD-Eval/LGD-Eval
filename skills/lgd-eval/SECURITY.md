# Security Policy / 安全策略

## Reporting a Vulnerability / 报告漏洞

If you discover a security vulnerability, please report it privately **before**
opening a public issue, so the maintainer can fix it before it is disclosed.

如发现安全漏洞，请先私下报告（勿先公开 issue），以便维护者在披露前完成修复。

**Contact / 联系方式**: open a private issue to the repository maintainer via
GitHub, or reach the LGD Ecosystem governance channel referenced in the repo.

## Supported Versions / 受支持版本

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ |
| < 1.0   | ❌ (dev) |

## Disclosure Policy / 披露策略

We will acknowledge valid reports within 7 days and aim to ship a fix in the
next patch release.
